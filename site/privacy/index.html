Privacy Policy

Last updated: September 28, 2026

Rogue Asset Store (“we”, “us”) is a public catalog of MCP servers and Agent Skills published by Rogue Development. This page explains what information we handle when you use the site.

1. What this site is

This website is primarily a static catalog. You can browse listings, search, and open documentation pages without creating an account.

2. Information we may process

  • Usage data. Standard web server or hosting logs may record IP address, browser type, referrer, and pages visited.
  • Contact messages. If you email us, we receive the address and content you send.
  • GitHub / third-party links. Links to GitHub or other sites are governed by those providers’ policies.

3. Cookies and analytics

This site uses Google Analytics (gtag.js) with measurement ID G-3457N10K0E to understand aggregate traffic (pages viewed, referrers, device/browser). Google may set cookies or use similar storage as described in Google’s privacy documentation. We do not use this tag for advertising remarketing on this catalog. Hosting platforms (for example GitHub Pages) may also collect basic telemetry required to serve the site. You can limit analytics via browser controls or Google’s opt-out tools.

4. How we use information

Any limited data we receive is used to operate and improve the catalog, respond to inquiries, and protect the service from abuse.

5. Sharing

We do not sell personal information. Data may be processed by infrastructure providers solely to host or deliver the site.

6. Data retention

Server logs are retained only as long as needed for security and operations. Email correspondence is kept as long as needed to handle your request.

7. Your choices

You can stop using the site at any time. For questions about privacy, contact us via the links in the site footer.

8. Changes

We may update this policy as the catalog evolves. The “Last updated” date above will change when we do.
